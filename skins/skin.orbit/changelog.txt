Orbit changelog

0.9.5 (2026-10-18)
- Library option bars (films / shows, music, other lists): pills whose label changes (the counts on
  ALL / UNWATCHED and the music tabs, VIEW) have fixed widths sized to the longest label; SORT and its
  arrow now sit at the end of the bar, so a new sort method or view never moves anything before it.
- Player controls panel (opened outside fullscreen) restyled in Orbit's language: navy dialog frame
  with the engraved ruler, poster / cover, wide title, mono times on the amber track, round
  transport Previous, Play/Pause, Stop, Next (no seek buttons) plus Shuffle / Repeat for music
  (amber when on). Fixed positions, so nothing shifts when Play becomes Pause.
- Home: the poster arc keeps the Movies band and the album arc its albums while the dial rests on
  another station (the arcs stay hidden there), instead of an empty path that made Kodi log
  "GetDirectory - Error getting" on every Home refresh; Movies <-> Settings no longer reloads.

0.9.4 (2026-10-18)
- Video OSD: no rewind / fast-forward buttons (Left/Right seek without the OSD). The ring's bottom
  arc now reads Previous, Play/Pause, Stop, Next, evenly spaced on the circle, so Stop sits right
  beside Play/Pause (it was the last tool on the far right). Tools row: Chapters, Audio, Subtitles,
  Video settings, Info, Player stats.
- Music OSD: the same transport (Previous, Play/Pause, Stop, Next; no seek buttons); tools are
  Shuffle, Repeat, Queue. Shuffle and Repeat light up amber when they are on, and the tool's name
  no longer shows twice (under the ring and in the tools panel).
- Info pages (film / show / episode and album / artist): Down from any button goes straight to the
  cast arc / tracklist beside the buttons (it used to take walking Right past every button).
- Home: a long genre list ("Drama / Romance / Fantasy") moves to its own line under the year and
  certificate instead of being cut off at the panel edge. Search results wrap the same line.
- Settings hub / dial lists: far rows fade into the blue ground instead of turning grey-black on it.
- Info page full story and More row: the deep-blue scrim instead of the old near-black one.

0.9.3 (2026-10-18)
- "ends 10:14 PM" fits in full under the runtime dial on Home, search, the library arc and the
  info page (the 12-hour clock's " PM" cut it to "ends 10:1..."): the runtime lines are 460 wide,
  centred on the dial as before. Other time labels checked (OSD, seek bar, playback info, clocks).

0.9.2 (2026-10-18)
- Background: a clearly blue, quiet deep-navy field with a soft glow behind the lens replaces the
  near-black ground (the mockups' #07090D / #121722 lift was crushed to plain black on the TV).
  Pre-rendered, dithered full-screen textures (media/ground/, _src/make_ground.py), one per layout:
  Home + search dial, library / music arc, list views, secondary windows + settings + info, now playing.
- Fanart backdrops (info pages, library art background, music stage) are darkened with the blue
  ground itself instead of a black scrim, so the screen never collapses to black.
- Palette follows: panels, raised rows, plates, dims and scrims are deep blue instead of blue-black;
  round buttons, row focus, badges re-rendered.
- Back: the library and music option bars now return Up / Right / Back to the visible view (arc,
  grid, episodes) instead of a hidden list (Up did nothing, Back skipped a folder).

0.9.1 (2026-10-18)
- Arcs: posters evenly spaced along the circle with a fixed gap (no overlaps hiding art), sizes
  falling off smoothly, tighter circle so the sweep reads; Home arcs wrap so neighbours sit above
  and below the lens from the first item. Arc tracks and record dials re-drawn to match.
- Settings stations: no labels over the icons; titles fit.
- Long titles fit everywhere (Home, search, library, info, music info, OSD, now playing): tiered
  wide Archivo sizes chosen with invisible probe textboxes (Container(id).NumPages).
- First-run view reset: skin timers set each content type's intended default view once
  (Majan-era view ids no longer leak through); the "Library opens in" setting re-arms them.
- Secondary windows (PVR, games, programs, pictures, profiles, playlists, event log, add-ons,
  weather, system info...): Orbit header with engraved ruler, soft lift, pill sub-nav, Orbit rows.

0.9.0 (2026-10-18)
- First build of Orbit ("browse on a dial"), forked from the Majan engine and redesigned throughout.
- Home dial: section ring (Search, Settings, Movies, TV, Music) with library totals in the centre;
  the focused section's content arcs out on the right (posters, album covers with the record
  peeking out, settings stations), info panel with rating ring and runtime clock sector.
- The arc: 11 offset-item slots on a circle, sliding along it on every move (one-frame
  OnNext/OnPrevious pulse + fadediffuse brightness by distance).
- Library: arc view, grid view (default selectable in skin settings), episodes dial list,
  dial list for every other list, option pills bottom-left.
- Info page = instrument panel: three gauges (rating, runtime with "ends at", your progress),
  story + codec chips, round buttons, cast on a shallow arc.
- Playback: circular scrubber OSD (amber progress ring + nib, time, ends, transport on the ring's
  bottom arc, tools row, straight chapter track), mini scrubber seek bar, instrument info strip.
- Music: album / artist arc with record dial, grid, now playing = the record turning inside the
  scrubber ring, music OSD on the ring arc, music info with record and round buttons.
- Search dial, settings hub dial list, skin settings with a detent-knob instrument, dialogs with
  engraved rulers, mono keyboard.
- Fonts: Archivo (wide / label / text static instances) + JetBrains Mono with slashed zero.
  All textures and frame sets generated by scripts in _src/.
