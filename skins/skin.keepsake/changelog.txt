0.9.6 (2026-10-21)
- Sets row in the Library panel; fix for controls disappearing or staying enlarged with Reduce motion on. Code clean-up for the Kodi repository checks.
- Clean-up details (kodi-review / kdk 0 errors): unused variables, includes and fonts removed, tags that repeat Defaults.xml dropped, label text moved to strings.po, Search now needs Skin Variables (script.skinvariables 2.1.21, required) to URL-encode the typed query, so titles with & + % | are found. Skin Variables is no longer optional, so the time-of-day notes are always on unless the setting turns them off. Game controller pictures (controller settings) were drawn with undefined colour names, so invisible; they use the skin colours now.
- Library leaf: a "sets" row (films only, when the library has sets) opens all sets in the same window; pick a set for its films, Back walks set -> all sets -> films. Sets use the films' views (prints, a list).
- Reduce motion: every animation include has one Hidden animation (Kodi resets only the first one when a control shows again, so the reduce-motion twin left the OSD, seek bar, dialogs and the info page's groups invisible after their first hide). Fades keep the normal timing; the volume / slider strip hides without its slide. _src/collapse_hidden_twins.py.
- Focused prints straighten (straight prints lift) while their list has focus and go back when it leaves, with Reduce motion on or off. KS_TiltFocus uses Conditionals on the list's focus instead of ten Focus animations, of which Kodi resets only the first (prints stayed straightened, after a jolt the other way, once focus left). The way back takes 240 ms instead of 180.
