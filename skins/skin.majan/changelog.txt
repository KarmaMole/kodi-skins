1.0.10 (2026-10-21)
- Sets row in the Library panel; fix for controls disappearing with Reduce motion on. Code clean-up for the Kodi repository checks.
- Code clean-up for the Kodi repository checks: unused code and fonts removed, on-screen text moved to the strings file, LF line endings. Search now encodes the typed text with Skin Variables (script.skinvariables, now required), so titles with & + % are found.
- Sets: while you browse films (and the library has sets), the Library panel has a "Sets" row: it opens
  the list of sets in the same Movies window, with the same views as films; picking a set opens its
  films, and Back walks back set -> all sets -> films. Not a Home menu item.
- Reduce motion: four animation includes (Anim_FadeVisible, Anim_TopStrip, Anim_RowStagger, Anim_BackgroundCrossfade,
  plus the unused side-panel / OSD-slide ones) carried two Hidden animations; Kodi only resets the first one when a
  control shows again, so with Reduce motion on, for example, the seek bar, the slider strip, the Home hub rows / artwork and
  the list view stayed invisible after their first hide. Now one Hidden animation each (fades: one fade for both
  settings; slides: the normal one, Reduce motion hides at once).

1.0.9 (2026-10-20)
- Library panel: in every library view, Left past the first item or Right past the last one (and the new OPTIONS
  word at the end of the header) opens a numbered panel with Update library, Clean library, View, Sort, Order,
  Show (watched), Search and Library settings - only the rows that apply (no Update / Clean in add-on folders).
  Back closes it and leaves you on the item you came from.
- Clean library asks first ("No, leave it as it is" has focus): Kodi's own clean command doesn't ask.
- VIEW: in the header (and the panel's View row) opens a view picker: each view of the window as a small drawing
  of its layout, its name, an accent underline on the current one; OK switches, Back keeps it. Movies, TV shows,
  seasons, episodes and music each list only their own views. (VIEW used to step to the next view.)
- System menu: Update library and Clean library, with a choice of videos or music.

- Language file: the strings.po header is valid gettext again (each header line one quoted string ending in \n).
- System menu: Live TV, Pictures, Favourites and Files (Live TV only when a PVR add-on is enabled); the card grows with the list.
- Reduce motion now also covers the Home 'newest' row slide and the progress toast: no gliding, everything lands in place.

1.0.7 (2026-10-20)
- New library view "Poster wall" (VIEW: POSTER WALL in the library header, films, sets, series, seasons).
  Full-screen, edge to edge, posters exact 2:3 and never cropped; the next row peeks in at the bottom and
  focus only lands on full rows. The header hides while the wall has focus; Up from the top row shows it.
  It is the last view in the list, so no folder changes its current view.
- New settings category 04 Poster wall: size (Small 11 / 12 across, Medium 8, Large 6), gap (16 px,
  Large 24) or edge to edge, border on the selected poster (or a slight zoom with the others dimmed),
  info overlay off / after 1 s / after 2 s (a card with title, times, plot, director and genres, media
  details; it covers the posters beside the selected one and flips at the right edge). Live preview.
