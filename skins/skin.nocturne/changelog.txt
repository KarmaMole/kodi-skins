0.9.6 (2026-10-21) - the library panel
- Library panel ("Library" card, the system menu's look): View, Sort, Order, Unwatched only, Search, Update library, Clean library and Media settings, only what applies. Opens with Left past the first frame or Right past the last one in every view (corridor, salon, stills, record bins; Right past the list's scrollbar) and from the new brass LIBRARY word. Back returns to the frame you came from.
- Engraved brass words in both library headers: VIEW (the current view) and LIBRARY, fixed widths. VIEW opens a view picker with framed schematic previews of each view (generated by _src/make_view_previews.py, no artwork), the current one marked "Now showing"; it opens on the current view, OK switches, Back closes with no change.
- Clean library asks first (Kodi's CleanLibrary() itself does not), with No focused.
- System menu: Update library and Clean library, each with a "which library?" card (Films and series / Music; Clean asks first, No focused).

v0.9.2 (2026-10-19) - speed
- The torch glides in 180 ms (was 480); plaques and glows appear without delay (140 ms); lists, shelf and corridors scroll in 200 ms; the info cast page slides in 200 ms; the room rest is 300 ms.
- Dust in the beam and the coloured halo are now opt-in (off by default): the looping dust made Kodi redraw every frame forever, and the colour service ran TMDb Helper on every focus move. Home no longer moves its hidden lists on focus unless the coloured halo is on.
- One opaque wall layer: the cornice is baked into plaster.jpg and the colour fill under the wall is gone; at most two full-screen layers (wall + shroud) on every room.
- Lighter textures: travelling shrouds 1024 (was 1920) drawn at 3840, static shrouds half size drawn 2x, halo 512.
- Home data lists draw 5 items with one 1 px poster each (was 8 items, poster + fanart).
